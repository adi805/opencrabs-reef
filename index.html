Connect the live bridge

  1. On the host that holds the OpenCrabs database, run npm run reef:serve (loopback only, port 4188).
  2. Open this page with ?agents=live to read the bridge.
  3. Without a server, npm run reef -- --db <path> --replay 300 prints the same events once.

No plugin and no gateway are involved: the bridge reads the OpenCrabs database directly, read-only.

Only lifecycle metadata. No prompts, messages, or tool output. Keep live mode local.
